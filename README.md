# PostgreSQL & MICRO SQL Complete Notes

A practical collection of **SQL and PostgreSQL notes, queries, examples, and assignments** created while learning and practicing relational database concepts.

This repository covers SQL concepts from the fundamentals of creating tables and inserting data to more advanced topics such as **SQL operators, set operators, functions, CASE statements, COALESCE, window functions, and JOINs**.

## 📚 Topics Covered

### Database & Table Operations

* Creating tables and databases
* Primary Keys and Constraints
* Data Types
* INSERT, SELECT, UPDATE and DELETE
* ALTER TABLE
* Adding, removing and renaming columns
* Changing column data types
* TRUNCATE and DROP
* ORDER BY and sorting

### 🔎 SQL Operators

* Arithmetic Operators
* Comparison Operators
* Logical Operators (`AND`, `OR`, `NOT`)
* `BETWEEN`
* `LIKE`
* `IN`
* `IS NULL`
* `DISTINCT`
* `LIMIT`

### 📊 Set & Aggregate Operations

* `UNION`
* `UNION ALL`
* `INTERSECT`
* `EXCEPT`
* `COUNT()`
* `SUM()`
* `AVG()`
* `MAX()`
* `MIN()`

### 🔤 SQL Functions

* String Functions
* Date & Time Functions
* Conditional `CASE` expressions
* `COALESCE()`
* Date formatting and extraction

### 📈 Window Functions

Practical examples of:

* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* Window-based `SUM()`
* Window-based `AVG()`

### 🔗 SQL JOINs

Examples and practice queries for:

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN
* CROSS JOIN
* SELF JOIN

The JOIN section uses related employee and department tables to demonstrate how data can be retrieved from multiple tables.

## 📂 CSV Import Practice

The repository also includes practical work on **importing CSV data into PostgreSQL tables** using the `COPY` command and CSV options such as headers.

## 📝 Practical Assignments

The notes contain **two SQL practice assignments** covering real database operations such as retrieving records, updating salaries, deleting records, modifying table structure, inserting employees, and using `CASE` expressions.
